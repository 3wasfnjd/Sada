# ضع الموديلات الثقيلة هنا

- الصيغ: `glb` أو `gltf` أو `fbx` أو `obj`.
- عند الرفع يشتغل GitHub Actions تلقائيًا ويُخرج نسخة خفيفة في `assets/` بخامات منقولة من الأصل، وصورة مقارنة في `docs/previews/<الاسم>_compare.png`.
- إعدادات اختيارية بملف بنفس الاسم `.json`، مثل `hero.json`:

```json
{ "name": "hero", "faces": 3000, "height": 0.95, "texture": 1024 }
```

| الحقل | المعنى | الافتراضي |
|---|---|---|
| `faces` | عدد الأوجه المستهدف للنسخة الخفيفة | 3000 |
| `height` | الارتفاع بالمتر (الخانة = 1 م)، البطل 0.95 | بلا تغيير |
| `texture` | حجم الخامة | 1024 |

# صدى — Sada (Echo)

لعبة ألغاز ثلاثية الأبعاد للجوال من **عبودين قيمز — Aboden Games**.

كل جولة لها وقت محدود. عند الضغط على «صدى» يرجع الزمن، وتظهر نسخة منك تعيد كل ما فعلته. الأبواب لا تنفتح إلا وأحد واقف على الدائرة المطابقة لها (لونًا وشكلًا)، فتستعين بأصدائك لتعبر. الغرف تُولَّد بلا نهاية، وكل غرفة يُتحقق آليًا من أن لها حلًا.

## الملفات
| المسار | المحتوى |
|---|---|
| `src/logic.js` | قواعد اللعبة ومولّد الغرف (بلا رسم ولا صوت) |
| `src/game.js` | الرسم (Three.js)، الشخصيات، الصوت، الإدخال، الواجهة |
| `src/shell.html` | الصفحة والتنسيق |
| `index.html` | الصفحة النهائية المجمّعة — لا تُعدَّل يدويًا |
| `tools/build.mjs` | يجمع `src/` في `index.html` |
| `tests/generator.test.mjs` | يتحقق أن كل الغرف المولّدة قابلة للحل وأن المولّد ثابت |

## البناء والاختبار
```
node tools/build.mjs
node tests/generator.test.mjs
```
GitHub Actions يشغّل الاختبار مع كل تعديل ويتأكد أن `index.html` مطابق لـ `src/`.

# طيف — Tayf

لعبة ألغاز من **عبودين قيمز — Aboden Games**، على الويب والجوال وMeta Quest.

عندك عدد محدود من الخطوات في كل دورة. لما تخلص، ترجع للبداية ومشيك يصير **طيفًا** يعيد خطواتك بالضبط وأنت تمشي معه. الباب ينفتح بس وأحد واقف على دائرته، فخلّ طيفك يمسك الباب وأنت تعبر للنجمة. المراحل تتولد بلا نهاية، وكل مرحلة يُتحقق آليًا إن لها حل وإنها تحتاج طيفًا.

## الملفات
| المسار | المحتوى |
|---|---|
| `src/logic.js` | قواعد اللعبة ومولّد المراحل (بلا رسم ولا صوت) — مشترك بين كل النسخ |
| `mobile/game.js` | نسخة الويب: الرسم (Canvas)، الشخصية المكعب، الصوت، اللمس، الواجهة |
| `mobile/shell.html` | صفحة نسخة الويب وتنسيقها |
| `index.html` | صفحة الويب النهائية المجمّعة — لا تُعدَّل يدويًا (ونسخة منها في `mobile/dist/sada.html`) |
| `tools/build.mjs` | يجمع `mobile/` و`src/logic.js` في `index.html` |
| `quest/` | نسخة Meta Quest (Godot) |
| `legacy/sada-3d-web/` | نسخة الويب القديمة ثلاثية الأبعاد «صدى» — محفوظة للرجوع فقط |
| `tests/generator.test.mjs` | يتحقق إن كل المراحل المولّدة قابلة للحل وإن المولّد ثابت |

## البناء والاختبار
```
node tools/build.mjs
node tests/generator.test.mjs
```
GitHub Actions يشغّل الاختبار مع كل تعديل ويتأكد إن `index.html` مطابق لـ `mobile/` و`src/logic.js`.
